# IT Security Guide

This guide lists the security rules for all devices and accounts.

## Passwords

Passwords must be at least fourteen characters long and unique for each service.
Use the company password manager and never share a password by email.

## Devices

Laptops must use full disk encryption and lock the screen after five minutes.
Lost devices must be reported to the service desk within one hour.

## Incident Response

Report a suspected phishing email with the report button in the mail client.
The security team confirms every reported incident within four working hours.
